D's Designer Boutique Web Architecture

Architected by R. S. Sanmugapriyan • Master of Computer Applications (MCA) at PSG College of Technology • Native of Palani, Tamil Nadu.

Project Purpose & Client Objectives

D's Designer is a premier bridal fashion atelier based in Coimbatore specializing in bespoke aari embroidery, hand-crafted designer blouses, and bridal lehengas.

Vibe Coding & Google Antigravity Architecture: Engineered using autonomous agent orchestration in Google Antigravity to rapidly deliver robust vibe-coding logic, desktop POS binaries, and mobile sync. All source code is pushed to GitHub (@sanmugapriyan2021-alt).

Core Objective: Replace unorganized social media inquiries with a high-performance, mobile-first couture showroom where bridal clients can zoom in on intricate zardosi craftsmanship and initiate direct WhatsApp order consultations with pre-filled design IDs.

Key Architecture

  • ✔
    Mobile-First Layout:

    Over 85% of traffic originates from mobile devices. The UI was built with touch-optimized thumb zones and zero layout shift.

  • ✔
    Direct WhatsApp Conversion Funnel:

    Each design item features an instant booking trigger that formats the specific product SKU and title directly into the boutique owner's WhatsApp message stream.
