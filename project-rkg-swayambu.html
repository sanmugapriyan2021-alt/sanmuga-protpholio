RKG Swayambu Agro & Retail POS Ecosystem

Architected by R. S. Sanmugapriyan • Master of Computer Applications (MCA) at PSG College of Technology • Native of Palani, Tamil Nadu.

Project Purpose & Client Objectives

RKG Swayambu is an agro-manufacturing enterprise producing scientific high-protein cattle feed pellets, traditional cold-pressed wood-pressed (Vaagai Marachekku) oils, millets, pulses, and authentic kitchen masalas.

Vibe Coding & Google Antigravity Architecture: Engineered using autonomous agent orchestration in Google Antigravity to rapidly deliver robust vibe-coding logic, desktop POS binaries, and mobile sync. All source code is pushed to GitHub (@sanmugapriyan2021-alt).

Core Objective: The client required a complete 3-tier software ecosystem to handle daily counter retail sales, give the CEO real-time mobile visibility across stock and cash flow, and offer customers an online delivery website.
