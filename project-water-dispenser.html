Automated IoT Smart Water Dispenser

A touchless, zero-contact hygienic water dispensing station engineered with ESP32 microcontroller, ultrasonic distance telemetry, and solenoid relay actuation.

Firmware Logic (ESP32 C++)

The system uses high-frequency ping bursts from the HC-SR04 ultrasonic transducer to detect when a container is placed within the 4cm - 12cm threshold zone. A sliding window debounce prevents accidental splashes or false positives. 

#define TRIG_PIN 5
#define ECHO_PIN 18
#define RELAY_PIN 23
#define THRESHOLD_CM 10.0

void loop() {
  long duration = pingUltrasonic();
  float distance = duration * 0.034 / 2;

  if (distance > 2.0 && distance <= THRESHOLD_CM) {
    // Container in proximity - energize solenoid
    digitalWrite(RELAY_PIN, HIGH);
  } else {
    // No container or removed - immediate cutoff
    digitalWrite(RELAY_PIN, LOW);
  }
  delay(100);
}
