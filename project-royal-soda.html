Royal Soda Manufacturing & Wholesale Distribution

Architected by R. S. Sanmugapriyan • Master of Computer Applications (MCA) at PSG College of Technology • Native of Palani, Tamil Nadu.

Project Purpose & Client Objectives

Royal Soda Factory is a regional soft drink manufacturer and wholesale beverage bottling plant producing traditional Paneer Soda, Lemon Soda, Orange Spark, and Cola beverages.

Vibe Coding & Google Antigravity Architecture: Engineered using autonomous agent orchestration in Google Antigravity to rapidly deliver robust vibe-coding logic, desktop POS binaries, and mobile sync. All source code is pushed to GitHub (@sanmugapriyan2021-alt).

Core Objective: The plant needed a structured wholesale ordering funnel to handle bulk crate deliveries to retail grocery shops, supermarkets, and catering halls, as well as onboarding new district distributors.

Wholesale Funnel Architecture

  • ✔
    Bulk Tier Ordering:

    Direct calculation for crate and pallet volumes with tiered wholesale pricing.

  • ✔
    Dealer Network Onboarding:

    Regional distributor application form with rapid route verification.
