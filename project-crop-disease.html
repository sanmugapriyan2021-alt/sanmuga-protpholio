AI Crop Pathology Diagnostic System

A transfer-learning convolutional neural network pipeline identifying 38 foliar disease classes across 14 crops with 96.8% accuracy.

🔬 Interactive Model Inference Playground

Select a plant specimen sample to execute the simulated MobileNetV2 classification engine:

PREDICTION: Tomato Early Blight (Alternaria solani) 98.4% Confidence

Concentric brown rings detected on foliar margins. Recommended remedy: Copper-based fungicidal spray and aeration spacing between rows.

Deep Learning Pipeline

  • ✔
    Dataset Preprocessing:

    PlantVillage benchmark composed of 54,305 curated images across 38 distinct crop-disease combinations, augmented with rotational and contrast shifts.

  • ✔
    Transfer Learning Architecture:

    Utilized MobileNetV2 with inverted residual blocks for lightweight, low-latency mobile device inference (42ms/frame on CPU).

  • ✔
    Evaluation Metrics:

    Achieved 96.8% top-1 validation accuracy, 0.97 F1-score across non-healthy plant foliage classes.
